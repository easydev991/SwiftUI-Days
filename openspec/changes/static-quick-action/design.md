# Design

## Context

Quick action «Добавить запись» сейчас регистрируется динамически в `AppDelegate.registerShortcutItem()` (`UIApplication.shared.shortcutItems` в `didFinishLaunchingWithOptions`). По документации Apple (`UIApplicationShortcutItem`) динамические actions недоступны до первого запуска приложения, а после установки обновления iOS показывает динамические actions предыдущей версии. Мотивация — см. proposal.md (Why). Обработка событий уже разделена по delegate-путям (cold — `configurationForConnecting` → `options.shortcutItem`, warm — `AppDelegateSceneDelegate`) и работает через маппинг по строковому типу, поэтому механизм доставки статического shortcut ничем не отличается.

## Goals / Non-Goals

**Goals:**

- Кнопка «Добавить запись» видна в меню иконки сразу после установки и обновления приложения, без первого запуска, на всех каналах поставки.
- Сохранить без изменений обработку: тип, локализацию заголовка, иконку, маршрутизацию и analytics.

**Non-Goals:**

- Никаких новых quick actions и никакой динамики в составе меню (список фиксирован на этапе сборки).
- Изменения UI-обработки (`MainScreen`, `RootScreen`), модели данных и ключей локализации.

## Decisions

1. **Статическая регистрация через `UIApplicationShortcutItems` в Info.plist, а не динамика.** Система регистрирует статические actions при установке — это единственный способ сделать action видимым до первого запуска; альтернатива (оставить динамику) не устраняет исходную проблему в принципе. Динамическая регистрация удаляется: при одновременном наличии статики и динамики система показывает обе, получились бы две одинаковые кнопки.
2. **Тип и заголовок — без изменений.** Тип `com.oleg991.SwiftUI-Days.addItem` сохраняется (обработка и тесты продолжают работать), заголовок — ключ локализации `Add Item` из `Localizable.xcstrings` (ru — «Добавить запись», en — «Add Item»); система локализует статический заголовок сама, новые ключи не нужны.
3. **Иконка — SF Symbol `plus` через `UIApplicationShortcutItemIconSymbolName`.** Системная «плюс»-иконка, визуально эквивалентна текущей `UIApplicationShortcutIcon(type: .add)`; альтернатива — `UIApplicationShortcutItemIconType` со значением `UIApplicationShortcutIconTypeAdd` (наследие 3D Touch, менее гибко).

## Risks / Trade-offs

- [Существующие пользователи обновятся, но не запустят приложение] → До запуска обновления iOS показывает динамику предыдущей версии — то же действие «Добавить запись», видимого регресса нет; после запуска кеш заменится статикой.
- [Изменение Info.plist при включённом `GENERATE_INFOPLIST_FILE`] → Явный файл `SupportingFiles/Info.plist` уже подключён в обеих конфигурациях и мержится с генерируемыми ключами; правка в него безопасна, проверяется сборкой.
- [Статические actions занимают лимит меню (до 4)] → Используется один action, лимит не достигается.

## Migration Plan

Обычный релиз без миграции данных. Откат — вернуть `registerShortcutItem()` и убрать ключ из Info.plist (коммит-реверт).
